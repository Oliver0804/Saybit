# Typeless 語音輸入 APP 深度研究報告

## 研究摘要

- **研究主題**：Typeless AI 語音輸入工具功能分析與競品比較
- **研究深度**：標準研究（4 輪）
- **完成輪次**：4 輪
- **研究日期**：2026-01-27

> [!abstract] 一句話總結
> Typeless 是一款結合 AI 智慧編輯的語音輸入工具，不只「聽寫」而是「理解意圖」，能自動去除贅詞、修正改口、格式化輸出，支援全平台（Mac/Windows/iOS/Android），免費版提供每週 4,000 字額度。

---

## 核心發現

### 發現一：不只是語音轉文字，而是「AI 寫作助手」

Typeless 與傳統語音輸入最大的差異在於，它使用大語言模型（LLM）來理解語意，而非僅做語音識別（ASR）。具體表現：

- **去除填補詞**：自動刪除「嗯」、「啊」、「你知道嗎」等口語贅詞
- **去除重複**：偵測並刪除重複說的內容
- **智慧改口**：中途改變想法時，只保留最終意圖
- **自動格式化**：將口述的清單、步驟、重點自動整理成結構化文字
- **語調適配**：根據當前使用的 App 自動調整輸出風格（如聊天軟體偏口語、工作郵件偏正式）

> [!example] 實際效果對比
> **你說的話**：「嗯…我想我們明天，對，明天早上九點開個會，討論一下那個新的專案。」
>
> **傳統語音輸入**：嗯我想我們明天對明天早上九點開個會討論一下那個新的專案
>
> **Typeless 輸出**：「我們明天早上九點開會，討論新的專案。」

### 發現二：全平台覆蓋，系統級整合

Typeless 是目前少數能全平台支援的 AI 語音輸入工具：

| 平台 | 狀態 | 發布時間 |
|------|------|----------|
| macOS | 已上線 | 2025-11-18 |
| Windows | 已上線 | 2025-11-18 |
| iOS | 已上線（第三方鍵盤） | 2025-12-24 |
| Android | 已上線（第三方鍵盤） | 2026-01（本週） |

- **桌面版**：系統級工具，按住快捷鍵即可在任何有輸入框的地方使用（瀏覽器、郵件、聊天、IDE、終端機）
- **行動版**：以第三方鍵盤形式運作，需在系統設定中啟用

### 發現三：免費額度在同類產品中最大方

| 產品 | 免費額度 | Pro 月費 | Pro 年繳 |
|------|----------|----------|----------|
| **Typeless** | **4,000 字/週** | $30/月 | **$12/月** |
| Wispr Flow | 2,000 字/週 | $15/月 | $12/月 |
| Willow | 2,000 字/月 | $15/月 | - |
| SuperWhisper | 基本功能免費 | 自帶 API Key | $84.99/年 |

> [!tip] 省錢建議
> 新用戶註冊即享 30 天 Pro 免費試用。試用結束後自動轉為免費版。若每週用量在 4,000 字以內（約每天 570 字），免費版已足夠日常使用。

### 發現四：隱私保護策略明確但有待獨立驗證

Typeless 強調三大隱私承諾：

1. **零資料保留**：語音處理完成後不保留錄音
2. **不訓練模型**：聽寫資料不用於任何模型訓練
3. **本地歷史**：所有聽寫歷史僅儲存在裝置上

> [!warning] 注意事項
> 雖然 Typeless 聲稱「local-first」架構，但 AI 編輯功能仍需聯網處理。與 SuperWhisper 的完全離線不同，Typeless 的語音資料會經過雲端 AI 處理後返回結果。目前缺乏 SOC2/HIPAA 等第三方獨立稽核報告。

## 競品比較

### Typeless vs Wispr Flow vs SuperWhisper

| 比較項目 | Typeless | Wispr Flow | SuperWhisper |
|----------|----------|------------|--------------|
| **定位** | AI 智慧聽寫 | 全場景語音輸入 | 隱私優先離線聽寫 |
| **平台** | Mac/Win/iOS/Android | Mac/Win/iOS | Mac only |
| **免費額度** | 4,000 字/週 | 2,000 字/週 | 基本免費 |
| **年繳月費** | $12/月 | $12/月 | $84.99/年 |
| **準確度** | 95%+ | 97.2% | 中等 |
| **隱私** | 零資料保留（雲端處理） | 雲端處理（可開隱私模式） | 完全離線 |
| **程式碼支援** | 基本 | 強（變數、函數名辨識） | 無 |
| **合規認證** | 無 | SOC2/HIPAA | 無 |
| **智慧編輯** | 強（格式化、改口、去贅詞） | 強（語調、格式化） | 基本轉錄 |
| **離線能力** | 需聯網 | 需聯網 | 完全離線 |

> [!tip] 選擇建議
> - **追求最佳文字品質和免費額度** → Typeless
> - **程式開發者或需要企業合規** → Wispr Flow
> - **極度重視隱私、需離線使用** → SuperWhisper

## 繁體中文使用建議

1. 安裝後進入設定 → 將翻譯模式的目標語言改為「繁體中文（台灣）」
2. 設置「偏好的語言變體」為繁體中文
3. 將常用專有名詞加入個人字典
4. 若出現簡體字，手動修正後系統會學習

## 結論與建議

### 主要結論

1. Typeless 是目前功能最完整的 AI 語音輸入工具之一，核心優勢在於「理解意圖」而非「逐字聽寫」
2. 全平台支援（Mac/Windows/iOS/Android）是其最大競爭優勢
3. 免費版每週 4,000 字的額度在同類產品中最為大方
4. 幻覺問題是目前最需要關注的風險

### 建議行動

- **輕度使用者**：直接使用免費版即可，每週 4,000 字足夠日常使用
- **重度使用者**：建議年繳方案（$12/月），性價比最高
- **重視隱私者**：注意其仍需雲端處理，若極度敏感建議選 SuperWhisper
- **程式開發者**：建議搭配 Wispr Flow 使用，Typeless 的程式碼辨識能力較弱

### 潛在風險

- 大型科技公司（Apple、Google）未來可能在系統級提供同等水準的語音輸入能力，削弱第三方工具的價值
- 幻覺問題若無法解決，可能導致用戶在重要場合誤用錯誤內容
